# Defect Lens v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Native execution is selected. Do not start a subagent cascade. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a reproducible local tabletop visual inspection workbench with bounded jobs, human corrections and honestly separated fixture/pretrained/owned-photo evidence.

**Architecture:** A FastAPI process persists jobs and reviews in SQLite and supervises one inference child. A React client uses the local API; versioned image-difference and ResNet18 patch scorers share alignment/calibration. A deterministic original dataset permits an offline demo while real captures remain an evidence gate.

**Tech Stack:** Python 3.12/uv, FastAPI/Pydantic, SQLite, Pillow/NumPy/OpenCV, optional torch/torchvision, React/TypeScript/Vite, pytest/Pyright/Ruff, Vitest/Playwright.

**Spec:** `docs/SPEC.md`; also read `EVALUATION.md` and `docs/RELEASE-STANDARD.md`.

## Global Constraints

- Own only `/Users/matthewgoralczyk/BentoLabs/portfolio/defect-lens`; every shell call sets this workdir, except an explicitly created clean-clone directory inside this project's `.runtime`.
- Python 3.12.x through uv; requires-python >=3.12,<3.13. Node 24 LTS locally/CI; documented tested local exception only if unavailable. No global configuration edits.
- API 127.0.0.1:8111; web 127.0.0.1:5111 with strictPort; exact CORS origin http://127.0.0.1:5111. Inspect conflicts, do not kill unknown processes.
- Full strict-check/CI environments use `uv sync --locked --extra features`; this installs libraries without weights/inference. Keep runtime torch imports behind the feature loader; no source/test exclusions or broad missing-import ignores.
- Resolve and lock actual dependencies at bootstrap. Per-project .venv, web/node_modules, .runtime and SQLite; no sibling service or shared mutable package.
- One inference process; 32 nonterminal jobs; 8 MiB image/9 MiB body; 8,000,000 pixels; 30-second job timeout; 1,536 MiB worker RSS; <=512 MiB stored bytes and <=10,000 jobs.
- Heavy ML lease: atomic mkdir `/tmp/bentolabs-portfolio-ml.lock` before weight load; owner token/PID/start identity; stop and join model child before release. Whole comparison benchmark owns one lease.
- Fixture/owned_capture and real_difference/real_pretrained are independent evidence labels. No automatic switch to fixtures or another model.
- No public repositories, pushes, releases, deployment, paid compute or model upload without specific authorization. Local scoped commits are authorized during execution; never use the resume app panel.
- Keep source/prose ASCII. Run strict Pyright across src/tests/scripts and strict TypeScript across source, unit tests, browser tests and configs. Do not exclude failing test files to make checks green.

## Review Focus

- A small compressed image with huge dimensions must be rejected before allocation: Task 2 decompression-bomb and dimensions tests.
- Mirrored/rotated or slightly translated images must align in the documented direction; failed alignment yields review: Task 3 spatial tests.
- A repeated HTTP request and a crash between artifact write and database commit must never duplicate an inspection: Tasks 5 and 6 transactional/idempotency tests.
- A stale correction form must preserve the user's note while reporting the conflict: Tasks 6 and 7 concurrency tests.
- A busy ML lease or second local server must not load weights, kill another process or leave a resident model after release: Tasks 4, 5 and 10 lifecycle tests.
